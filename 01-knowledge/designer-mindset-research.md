# Designer Mindset & Audience Retention — Hindi/Hinglish AI-Tools Reels
## Two-character animated explainer, 9:16, 40–80 seconds, comment-keyword CTA

**Context restated:** Indian personal-brand Instagram account, Hindi/Hinglish vertical reels teaching free AI tools + content-creation skills. Two animated characters — a human host who asks simple questions, a cute AI assistant who explains. Ends with comment-a-keyword for a free resource. Creator's diagnosis: graphics feel dull and patched-together. This report rebuilds the format from professional process + retention science.

**How to read the numbers:** Instagram and YouTube publish *signals and definitions*, not most of the "% retention" benchmarks circulating online. Where a number is a creator-community aggregate or a vendor study, it is labelled as such. Do not treat any single benchmark as a platform law — compare each reel against your own last 10 similar reels, which is YouTube's own advice.

---

## Summary — the one-sentence rebuild

**Professionals do not "make graphics prettier in the edit." They lock message, script timing, look, and motion rules on stills and a timed animatic *before* animating, then animate to a system (one palette, one type scale, one easing family, one spacing grid) so every scene belongs to the same world — and they script retention the same way: one open loop, a payoff every few seconds, a visual change every 2–4 seconds, and the CTA only *after* the payoff.**

For this format, the fix is therefore 70% pre-production: a 1-page design system + a beat-sheet script template. Animation polish is the last 30%.

## Findings

### A1. Professional process — brief → script → storyboard → styleframes → design system → animation → sound → iteration

A complete motion workflow is described as a linear chain of eight gated stages — brief, script and boards, styleframes, animatic, animation, sound, review rounds, delivery — where each stage converts an *approved* artefact into the next, more expensive one, and "animation should never start before the work has passed through a fixed sequence of gates" [Art of Styleframe, verified live 2026-11-16](https://artofstyleframe.com/blog/motion-graphics-production-workflow/). A second end-to-end guide uses the same order: brief → storyboard → animatic → design → animation → sound → export → testing, with "design before you animate" as the explicit principle [601 Media, index](https://www.601media.com/step-by-step-designing-motion-graphics-that-engage/).

**What each gate locks — and what it costs to change later:**

| Gate | Output (for a solo reel creator, scaled down) | Locked at this gate — do NOT decide later |
|---|---|---|
| 1. Brief (10 min) | One line: audience + single promise + duration + one CTA. E.g. "For a student who edits on phone: 1 free tool, 3 steps, comment TOOL" | Audience, ONE idea, length, CTA keyword |
| 2. Script (timed) | Spoken words counted to duration. Natural VO runs ~140–160 wpm, so 60s ≈ 140–150 words [Art of Styleframe, verified live](https://artofstyleframe.com/blog/motion-graphics-production-workflow/); general planning average is 150 wpm, ~120 for slow/clear explainers, ~170 for fast clips [QuickVeed, index](https://quickveed.com/blogs/script-length-for-video) | Every word, order of ideas, where the payoff lands |
| 3. Storyboard | One rough panel per beat, each tied to a script line: what is on screen, what moves, on-screen text | Shot list, full-screen vs character moments |
| 4. Styleframes (2–3 stills) | Finished-quality stills: opening, busiest mid-reel shot, end/CTA card. "A styleframe is a single still, finished to final render quality, that shows exactly how one moment will look, and its approval locks the visual language for everything downstream" [Art of Styleframe](https://artofstyleframe.com/blog/motion-graphics-production-workflow/) | Palette, type, character look, lighting, background world |
| 5. Animatic | Storyboard panels cut to scratch/final VO at real duration — every panel holds exactly as long as its shot will | Timing, cut points, pause lengths. This is where retention is *tested cheaply* |
| 6. Design system | Reusable components (see A2/A4): character poses, caption style, card, icon set, transitions | All recurring visuals become templates, not one-offs |
| 7. Animation (3 passes) | Pass 1 blocking (linear, no polish) → Pass 2 timing/easing → Pass 3 secondary motion/polish [Art of Styleframe](https://artofstyleframe.com/blog/motion-graphics-production-workflow/) | Motion only — no new ideas, no new colours |
| 8. Sound + iteration | VO locked first, then music/SFX mixed to picture; review against retention graph after posting | Next reel's fix list comes from dip timestamps, not opinions |

**Mentality shifts behind the process:**
- **The pipeline is the product.** Storyboards/styleframes/animatics exist to let you reject something while it is still cheap. Changing colour in a styleframe = minutes; in a rendered animation = re-rendering every scene it touches.
- **One named decision-maker, two review rounds per stage.** Round 1 may change structure; round 2 only detail; after approval it is locked. Solo creators should impose this on themselves — "one more idea" after animation starts is the #1 cause of patched-looking reels.
- **Timing is the first prototype, not the last polish.** If the animatic (ugly grey boxes + VO) is boring, no amount of easing will save it.

> **Solo-creator compression:** Studios budget 6–7 weeks for a 60–90s explainer with a two-person team [Art of Styleframe](https://artofstyleframe.com/blog/motion-graphics-production-workflow/). You should NOT copy the duration — copy the *order*. For a repeatable series, gates 4+6 are done ONCE for the whole series (your format bible), so each new reel only needs brief → script → board → animatic → animate, which can be a single day.

### A2. Why pro graphics look "perfect" and scenes feel "real" instead of dull

Nothing here is talent-magic. It is a small set of decisions repeated without exception:

**1. Visual hierarchy — exactly one hero per frame.** Rank every element 1–3; style only rank-1 as prominent; a greyscale screenshot should reveal the ranking in 3 seconds. Adjacent levels should differ by one full step in ONE channel (size ×1.25, or weight 400→700, or a clear lightness jump) — three small tweaks read as noise [ClawHub Design skill synthesis, index](https://clawhub.ai/ivangdavila/skills/design). In a reel frame: either the character's face, OR the tool screenshot, OR the big word — never all three at equal size/brightness.

**2. One idea per frame/screen.** Directly supported by learning science: Mayer's multimedia principles — coherence (remove extraneous material), signalling (highlight the essential), segmenting (one chunk at a time), and *temporal contiguity* (words and pictures at the same time, not one after another) — derived from 200+ experiments [GrowthEngineering / Mayer synthesis, index](https://www.growthengineering.co.uk/multimedia-learning-theory/). The redundancy principle matters most for this format: graphics + narration work; graphics + narration + *identical full text* overload the visual channel. Captions are the exception for muted viewing (see A4) — but a graphic should *show* the step, not re-type the sentence.

**3. Typography discipline.** Use one typeface family (at most two: display + body), 2 weights, and a fixed 3-level scale — e.g. Headline / Subhead / Label with fixed sizes, weights, line-heights (example scale: 64px bold / 32px semibold / 20px medium in a design doc) — and never improvise sizes scene-by-scene [Cursa 2D Motion Graphics style guide, index](https://cursa.app/en/page/style-choices-for-2d-motion-graphics-color-type-shape-language-and-layout-rules). "Patched" is usually just 5 different font sizes/weights that were each invented in the moment.

**4. Limited colour system.** Build a 3-part palette — primary, accent, neutrals — keep accent to ~5–10% of screen area [Cursa](https://cursa.app/en/page/style-choices-for-2d-motion-graphics-color-type-shape-language-and-layout-rules), or the classic 60-30-10 split (60% neutral surface, 30% secondary, 10% accent, accent only for interactive/state/important elements) with WCAG contrast floors 4.5:1 for body text [ClawHub Design](https://clawhub.ai/ivangdavila/skills/design). For this format: assign colours *meaning* — e.g. Host = warm neutral world, AI assistant = one accent colour, "free tool / payoff" = second accent used ONLY at payoff + CTA. If the accent appears everywhere, it signals nothing.

**5. Consistent spacing.** One base unit (8px) and a scale 4/8/16/24/32/48/64; between-group gap ≥2× within-group gap [ClawHub Design](https://clawhub.ai/ivangdavila/skills/design). On a 1080×1920 canvas, that means: same margin from edges in every scene, same gap between character and card, same caption position. The eye reads consistent spacing as "real place"; random placement reads as collage.

**6. Easing & motion curves — never linear.** Disney's 12 principles, codified by Johnston & Thomas in *The Illusion of Life* (1981), still govern motion graphics; the heavy hitters for this format are easing, timing, anticipation, and follow-through/overlap [MadeGoodDesigns, index](https://madegooddesigns.com/animation-principles/) [Adobe, index](https://www.adobe.com/in/creativecloud/roc/blog/video/animation-principles.html):
- *Slow in / slow out (easing):* real objects accelerate and decelerate; they never move at constant speed and snap-stop. Linear motion is the single fastest way to look robotic/cheap.
- *Anticipation:* a small opposite move before the main action (character crouches/dips ~10–20% of main-action duration before jumping/popping) tells the viewer something is about to happen so they don't miss it.
- *Follow-through / overlapping:* parts keep moving after the body stops, at different rates (hair, dupatta/cap, assistant's antenna/bubble settles 0.1–0.3s later with softer easing). Lockstep start/stop = fake.
- *Staging + appeal:* direct attention to one clear silhouette/action; characters need a readable, appealing shape language repeated everywhere.

**7. Motion matched to voiceover words.** The graphic for a word must land *on* that word (temporal contiguity, above), not 1s before/after. Pros animate to the VO waveform in the animatic; amateurs animate a generic loop and lay VO on top. A practical test: mute the reel — you should still follow the story from visuals alone; then listen audio-only — you should still follow it. Both must work.

**8. Restraint & negative space.** Empty space is what makes the hero element hero. A frame that is 40% empty will look more premium than a frame filled edge-to-edge with stickers. One dominant experiment/focal point per scene, surrounded by stable structure [Eidon design system, index](https://www.eidoncreative.com/design-system/).

**9. Depth / lighting consistency for characters (why scenes feel "fake").** Characters look pasted-on when: light direction, shadow softness, colour temperature, outline weight, or ground shadow differs between character and background, or changes scene to scene. Fix as a system: one light direction (e.g. top-left) for the whole series, one soft elliptical ground shadow under every character in every scene, same outline stroke weight, background slightly desaturated/lighter than characters so characters sit *in front* in the same world. Flat, optically perfect renders read subconsciously as synthetic — human work carries consistent depth cues (background blur/value shift, vignette, shadow) across all scenes [VdoBloom AI-for-motion analysis, index](https://vdobloom.com/blog/ai-for-motion-designers/) — consistency matters more than photorealism for 2D characters.

### A3. How designers use AI tools inside this workflow — AI generates vs human judges

"In 2026, AI fits into an After Effects workflow in three places: language models that write expressions and scripts, code-first tools that render motion an AI agent writes as code, and generative models that supply raw material such as backgrounds, textures, b-roll, loops and cut-outs. It does not replace the comp. Kerning, frame-exact typography timing and brand-exact vectors still belong to you" [VdoBloom, Oct 2026, index](https://vdobloom.com/blog/ai-for-motion-designers/). Core line: **"AI feeds the comp, it doesn't replace it"** — AI is good at making *assets* and writing *code*; weak wherever the result must match a spec to the pixel or the frame.

| Stage | Let AI (Claude / ChatGPT / generators) do this | Human eye MUST judge / do this |
|---|---|---|
| Brief / script | 10–20 hook variants, dialogue drafts, Hindi/Hinglish phrasing options, word-count/timing checks, "explain it simpler" passes | Which ONE idea, is the promise true, does the joke land for *this* audience, final word choice |
| Storyboard | Shot-list from script, composition suggestions, reference gathering | Reading order, what the hero element is, cutting a beat |
| Styleframes / assets | Palette variations, moodboards, background plates, textures, icon drafts, character pose exploration | Taste: pick one direction and *stop exploring*; brand/character consistency across frames |
| Animation | After Effects expressions/ExtendScript, Remotion/GSAP code for templated/data-driven graphics, auto-rigging, in-between drafts, caption timing drafts (Whisper etc.) | Easing feel, anticipation/follow-through timing, frame-exact word landing (e.g. word on frame X, ease-out over 8 frames — video models cannot do this reliably), final motion polish [VdoBloom](https://vdobloom.com/blog/ai-for-motion-designers/) |
| Sound | SFX/music drafts, voice drafts, beat maps | Whether a sound *fits the beat*, mix levels, comedic timing |
| Iteration | Summarise retention dips + comments into a fix list, generate variant hooks for testing | Diagnosing *why* a dip happened; AI + retention graph tells you *where*, not *why* |

Also: "It won't art direct. It won't replace the visual instincts you've spent years building. But as a creative thinking partner for the pre-production and post-production phases, it earns its subscription" — AI is strong at exploratory/executional ends (palette/type variations, first-draft asset systems, briefs, stress-testing concepts), weak at intent, cultural context and creative direction [House of GAI FAQ, index](https://www.houseofgai.com/ai-tools-faqs-graphic-design). And from animation practice: "AI replaces workflows, not artists. Artistic judgment, storytelling rhythm, character emotion, and cinematic language still rely entirely on human creativity" [Tripo AI-in-animation overview, index](https://www.tripo3d.ai/blog/ai-in-animation).

**Warning specific to this creator:** asking an AI to generate each scene's graphics independently *is* the patched look. The professional use is opposite: human locks the design system once, then AI generates *inside* those constraints (same palette hexes, same type scale, same character sheet in every prompt/template).

**Psychology triggers — what makes them stop / save / share / comment / follow:**

- **Stop (0–2s):** Recognition of *their* pain in *their* words ("Client ne bola kal subah chahiye… aur tool paid hai?") + a visible result they want. Not "AI tools part 7".
- **Save:** Perceived future utility — a tool name + steps they cannot memorise in one watch. Lists, steps, prompts and checklists are save-bait by design. Saves are named by Instagram among key Explore predictions (likes, saves, shares) [Mosseri Ranking Explained 2023 via iImagined, index](https://iimagined.ai/blog/instagram-saves-vs-likes) — but saves are NOT in Mosseri's Jan 2025 top-3 (see B6).
- **Share / Send (DM):** "This is exactly for my friend who edits / is starting a page." Sends are the strongest non-follower signal (below). Design a *named recipient* into the script: "Apne us dost ko bhejo jo abhi bhi manually caption likhta hai."
- **Comment:** A single keyword for a genuinely useful free resource is a low-friction, high-intent comment — the viewer gets the prompt/template/checklist they just saw used, not a generic PDF. One ask only, one word only (see B7).
- **Follow:** A *series promise kept* — same characters, same world, "roz ek free tool" predictability. People follow a format they can predict the pleasure of, not a single viral reel.

### B6. Retention science for 40–80 second reels

**What Instagram actually said (primary):** On 21 Jan 2025, Adam Mosseri named the three signals that matter most for ranking: **watch time, likes per reach, and sends per reach** — likes weigh slightly more with followers, sends slightly more with non-followers; track average watch time, likes/reach, sends/reach in Insights [Mosseri via iImagined, checked Oct 2026, index](https://iimagined.ai/blog/instagram-saves-vs-likes); [Zyntaflow ranking summary, index](https://www.zyntaflow.com/blog/instagram-algorithm). Everything else (saves, comments) is used but is not in that top-3.

**What YouTube actually defines (primary):** YouTube's retention report defines **Intro = % still watching after the first 30 seconds**, Top Moments = almost no drop-off, Spikes = rewatched/shared moments, Dips = skipped/abandoned moments; key moments need a video ≥60s with ≥100 views, data takes 1–2 days [YouTube Help via RecurPost, index](https://blog.recurpost.com/how-to-read-an-audience-retention-graph/). YouTube states no universal target % — a Content-tab tip cites 50%+ still watching at 30s as strong. Use definitions, not invented thresholds.

**The first 1–3 seconds:**
- Viewers decide in roughly **1.3–1.7 seconds** whether to swipe; ~50–60% of all drop-off in third-party Shorts analyses happens in the first 3 seconds (no platform publishes this figure — treat loosely) [Zella](https://zellahq.com/blog/retention-editing-keep-viewers-watching/); swipe decision 0.3–3s in eye-tracking/platform summaries [Director hooks reference, index](https://github.com/hoodini/ai-agents-skills/blob/HEAD/skills/director/references/04-engagement-psychology-hooks.md).
- Socialinsider's 2026 benchmarks (35M posts) as reported put 60.5–65.5% of viewers skipping a Reel within 3 seconds [via SuperDirector, index](https://superdirector.app/how-to/write-scroll-stopping-hooks) — this conflicts in magnitude with smaller creator samples claiming 70–85% 3s-hold for winners. **Report the disagreement honestly: most viewers leave early; winners hold far more. Judge by your own 3s-hold trend, not an absolute.**
- Working operator benchmarks (NOT platform-published): >60% 3-second hold strongly out-reaches <40% hold; pattern-interrupt hooks retain ~72–84% at 3s in one 2026 aggregator [Sled/Retensis, index](https://sled-inst.pro/en/articles/instagram-reels-retention). Use as directional targets only.
- Therefore: **frame 0.0 must already contain** — motion, the result/payoff visual, and hook text at full opacity. No logo, no "hey guys", no fade-in, no character walking in.

**Curiosity gaps & open loops (the psychology, correctly cited):**
- Loewenstein's information-gap theory (1994, *Psychological Bulletin*): curiosity is a deprivation-like response to a perceived gap between what one knows and what one wants to know; it is an **inverted-U** — too small a gap = boredom, too large = overwhelm/disengagement; a small dose of information *primes* curiosity, so hooks must give partial information, not withhold everything [Director hooks reference](https://github.com/hoodini/ai-agents-skills/blob/HEAD/skills/director/references/04-engagement-psychology-hooks.md).
- Zeigarnik effect (1927): interrupted/incomplete tasks are remembered better than completed ones — the popular justification for open loops/cliffhangers. Honest caveat from the same source: replication attempts are mixed; the effect is strongest when the task is personally meaningful. Use open loops, don't oversell them as proven law.
- Practical translation: **1 macro-loop** (opened 0–5s, closed only at payoff ~40–50s) + **micro-loops every 5–8 seconds** (open a small question, resolve it, open the next while the macro-loop stays open) [Copi-writer viral skill synthesis, index](https://github.com/prrcarvalho/video-editing-ai/blob/HEAD/.agents/skills/copi-writer-viral/SKILL.md).

**Pattern interrupts & re-hooks — how often:**
- Visual pattern interrupt every **2–4s** (A4); script-level re-hook every **5–8s** (new claim/question/angle, not just a zoom); a bigger re-engagement beat roughly every **20–40s** in longer MrBeast-style editing (re-hook every 20–40s, stakes raised, no dead air) [OutlierKit MrBeast analysis — outside analysis of published videos, not internal data, index](https://outlierkit.com/resources/mrbeast-growth-strategy/). MrBeast's own leaked production guide scales this as a re-engagement around minute 3 and minute 6 for long-form [ScriptHooks summary, index](https://scripthooks.ai/blog/mrbeast-curiosity-loops) — **do not copy minute-timings into a 60s reel; copy the principle at 5–8s scale.**
- Place interrupts *just after a payoff lands* — the moment a question is answered is the moment the viewer feels free to leave. That boundary needs the next question immediately.

**Payoff timing & mid-roll drop-off:**
- Deliver a **finished micro-payoff every ~4–5 seconds** (measured: Hormozi listicle landed 12 complete payoffs in 52.8s, one every 4.2s) [PandaStudio](https://www.writepanda.ai/blog/hormozi-style-shorts-editing/) — a tip, a step completed, a joke landed. The macro-payoff (the tool actually doing the impossible thing) must land at **~70–85% through the reel** (40–50s in a 55s reel), not at 95% — viewers who feel tricked don't comment, they leave.
- Classic dip points in 40–80s explainers: (1) 0–3s weak hook, (2) ~10–15s after the setup when explanation turns into lecture, (3) the step-list middle (step 2 of 3 is the most-skipped), (4) any CTA/follow-request inserted mid-reel, (5) a slow outro/"toh dosto…" wind-down. Fixes in order: result-first hook, re-hook at 8s, make step 2 the shortest + add humour there, CTA only after payoff, end abruptly/on the loop line.
- Read your own graph like YouTube defines it: a sharp dip = one moment to cut/shorten/move; a spike = rewatched/shared (either brilliant or confusing — check comments to tell which).

**Loopable endings:** Script the last line so it syntactically/visually flows into the first line (last frame matches first frame composition), so a replay feels seamless and adds watch time. Never pad length to force a loop, and never signal "the end" (no "bye, follow for more" fade-out) [Octomind hooks guide, index](https://octomind.run/tap/skills/video-hooks).

**Length honesty for 40–80s:** Shorter reels complete at higher rates (e.g. ~72% completion for 15s vs ~46% for longer in Zebracat/Metricool via CreatorLane) [CreatorLane](https://creatorlanehq.com/blog/first-three-seconds-instagram-hook-anatomy-2026). A 60–80s reel must therefore *earn* its length with density — if the idea fits in 45s, ship 45s. Do not stretch a 30s idea to 70s.

### B7. Script structure for a two-character Q&A explainer

**Word budget:** 45s ≈ 110–125 words, 60s ≈ 140–150 words at conversational pace (A1). Hindi/Hinglish delivery with pauses for jokes/demos: plan at the *slow* end (~120–135 wpm) and read aloud with a timer — numbers, English tool names and pauses all add time.

**Dialogue rules:**
- **Line length: 4–10 words per line, one line = one idea = one caption group sequence.** Host lines shorter (3–7 words — questions, reactions, objections). Assistant lines slightly longer but never a monologue >12–15 words without an interruption/reaction shot.
- **Q–A rhythm: question every 7–12 seconds.** The host is the viewer's surrogate — he must ask what the viewer is thinking *at that second* ("Par ye paid hoga na?", "Phone pe chalega?"), not dump all questions at the start. Each answer resolves a micro-loop and the host's next doubt opens the next one. This is Veritasium's misconception engine in miniature: state the viewer's wrong belief, then rebuild it.
- **Speaking split: Host ~35–40%, Assistant ~60–65%.** Host owns hook, doubts, humour, and CTA setup; assistant owns explanation and payoff. If the assistant speaks >75%, it becomes a lecture with a mascot. If the host speaks >50%, nothing gets taught.
- **Humour/roast beats: every 12–18 seconds, 3–4 per 55s reel, always at the host's expense or the *old way's* expense — never at the viewer's.** Pattern: host does it the slow/dumb way → assistant roasts lightly → demo proves it. Humour must be a pattern interrupt (expression change + SFX + punch-in), not just a funny line over a static frame. Keep one running gag per series (catchphrase, prop, assistant's deadpan pause) — predictability builds follow.
- **CTA placement — after payoff, in the last 8–12 seconds, one ask only.** The proven "yap" structure ends: …named steps → save-bait interrupt (a dense summary/bonus screen viewers must pause/save to read, 3–5s, which also acts as a pattern interrupt right before the ask) → CTA 8–12s: "Comment TOOL, main tumhe saare prompts + checklist bhej dunga" [Jimmy Reilly yap formula, index](https://jimmyreilly.com/how-to-write-yaps-that-sell/); [summary, index](https://damonnelson.com/blog/yaps-explained-seven-part-formula.html). Rules: (1) Never put the main CTA before the payoff — it signals "video is over" and kills retention; a *soft* seed is allowed at ~15s ("end mein main iski prompt-list dunga") because that *opens* a loop instead of closing one. (2) Say it AND show it as text (muted viewers). (3) The free resource must be the exact artefact used in the reel (the prompts/checklist just demonstrated) — bait-and-switch kills comments on the *next* reel. (4) One keyword, one word, easy to spell in Roman script.

**Beat template (55s):** Hook/result (0–3s) → Pain + promise + loop-open (3–8s) → Step 1 + micro-payoff (8–18s) → Doubt/roast re-hook (18–25s) → Step 2, shortest (25–35s) → Step 3 / "lekin asli trick…" re-hook (35–42s) → Full payoff demo (42–50s) → Save-bait summary (50–53s) → CTA + loop line (53–58s, loops to frame 1).

### B8. Common mistakes that make animated explainers feel dull / fake / patched — and the pro fix

| # | Mistake | Why it feels dull/fake | Professional fix |
|---|---|---|---|
| 1 | Static talking heads: two characters bobbing, mouths flapping, nothing else changes for 5–10s | No attention reset; brain habituates in seconds | Visual change every 2–4s: expression, pose, prop, punch-in, full-screen insert. If dialogue runs long, cut to what they're *talking about* |
| 2 | Graphics lag behind or merely repeat narration (character says "click export", 2s later a generic export icon floats in; or screen shows the exact sentence being spoken) | Violates temporal contiguity; adds cognitive load without adding information (Mayer redundancy) | Animate to the VO waveform: graphic lands ON the word, and *shows* the action (cursor clicks, result appears) instead of labelling it |
| 3 | Text overload: full sentences, 3 text blocks + captions + stickers at once | Visual channel overload; viewer reads nothing and leaves | One block per moment, ≤42 chars/line, captions 1–4 words/group, one hero per frame (A2/A4) |
| 4 | No visual change for several seconds / dead air, pauses >0.3–0.5s between lines | Retention leak; dips form exactly there | Cut every pause >~0.3s in dialogue edit; leave a breath ONLY after a punchline/payoff so it lands [Zella](https://zellahq.com/blog/retention-editing-keep-viewers-watching/) |
| 5 | Every scene designed separately: different fonts, colours, backgrounds, character sizes | No design system = collage. This is the literal "patched" look | Build the format bible ONCE (A1 gates 4+6): 3 styleframes + component library; every new scene assembled from it, never invented |
| 6 | Linear easing, everything starts/stops together, no anticipation | Robotic, weightless, "PowerPoint" feel | Ease everything (no linear), anticipation dip before pops, follow-through settle 0.1–0.3s on secondary parts (hair/antenna/card) |
| 7 | Character and background in different worlds: mismatched light, no ground shadow, outline weights differ | Subconscious "sticker on photo" fake feeling | One light direction, one ground-shadow style, background desaturated vs characters, same stroke/palette in every scene |
| 8 | Hook is an introduction ("Aaj hum seekhenge…") with logo/greeting/fade-in | Burns the entire 1.7s decision window on zero information | Frame 0.0 = result + hook text + motion. Introduction is deleted, not shortened |
| 9 | Lecture middle: assistant monologues steps 1-2-3 with no host interruption | No micro-loops; step 2 is where viewers leave | Host doubt/re-hook every 7–12s; shortest step in the middle; humour beat at ~20s and ~35s |
| 10 | CTA in the middle, or 3 CTAs (follow + save + comment + link in bio) | Signals "over", splits intent, each ask weakens the others | One CTA, after payoff, last 8–12s, said + shown; soft loop-opening seed earlier is the only exception |
| 11 | Slow outro: "Toh dosto, ummeed hai… follow kar lo" over a fading card | Teaches the algorithm viewers leave before the end; kills loop replays | End abruptly on the payoff/CTA line; last frame/line loops into first frame/line |
| 12 | Music/SFX as wallpaper: same loop throughout, hits unrelated to action | "Temporally deaf" edit — visuals and audio in separate worlds | Cut/change on audio beats; whoosh/pop/click SFX *on* graphic actions; duck music under every payoff line; silence (0.3s) before the biggest reveal |

## Blueprint — Design + Script for a 45–60s Two-Character Explainer Reel

### 1. The Format Bible (build ONCE, use for every reel)

**Canvas & safe zone:** 1080×1920. All key text/faces inside y 270–1250, x 65–940 (keep right 140px clear). Captions centred, y 1000–1250. Hook title y 280–500.

**Colour system (example — pick yours once, then never deviate):**
- Background world: warm off-white / soft neutral (60%)
- Host world: warm secondary — e.g. deep navy clothing, warm skin tones (30% shared with UI cards)
- AI Assistant + "magic/payoff" accent: ONE vivid colour, e.g. electric mint or amber (10% max) — used ONLY for: assistant, payoff moments, keyword/CTA. Nothing else may use this colour.
- Text: near-black (#111–#1A1A1A) on light, white with dark stroke/shadow on dark.

**Typography:** One sans family, 2 weights (Bold + Regular/Medium). Fixed scale on 1080 canvas: Hook/hero word 90–120px bold, card headline 64px bold, label/caption 48–60px. Same sizes every reel.

**Characters:** One character sheet each: 6 expressions (host: curious, shocked, sheepish, proud; assistant: neutral, deadpan, excited, "told-you" smirk), 4 poses, one light direction (top-left), one soft ground shadow, same stroke weight. Assistant always enters from the same side with the same anticipation-dip + ease-out + antenna follow-through settle — this signature motion becomes brand recognition.

**Motion system:** One easing family for everything (ease-out for entrances, ease-in-out for moves, spring/overshoot ONLY for payoff + joke moments). Entrances 250–400ms, scene transitions 300–500ms. No linear motion anywhere. Every graphic action gets its matched SFX from a fixed 6-sound kit (pop, whoosh, click, ding-payoff, record-scratch-roast, silence).

**Caption system:** 1–4 words/group, swap on speech (~0.8–1.0s), white bold, dark shadow, ONE accent word in assistant-accent colour per group max. Fixed position, never moves.

**Scene templates (only 4 allowed):** (T1) Two-shot dialogue, (T2) Single-character reaction close-up, (T3) Full-screen demo/card (tool UI, steps, before/after), (T4) Summary/CTA card. If a scene doesn't fit a template, the script is wrong — rewrite the script, don't invent a 5th layout mid-reel.

### 2. Worked script — topic example: "Free AI tool se reel ke captions auto-generate karo"
*~150 words spoken, target 55s. Replace the tool/topic; keep the beats, timings and split.*

| Time | Who | Line (Hinglish, as spoken) | Visual (template) | Retention job |
|---|---|---|---|---|
| 0.0–3s | Host (shocked, full result on screen) | "Ye captions maine haath se NAHI likhe!" | T3: finished captioned reel playing, hook text at frame 0.0: "Captions FREE mein auto?" | Result-first hook, macro-loop opened: *kaise?* |
| 3–8s | Assistant | "Ek free tool tumhaari awaaz sunke, word-by-word captions bana deta hai. Last mein main prompt-list bhi dunga." | T1 two-shot, assistant accent glow | Promise + CTA seed as open loop |
| 8–18s | Assistant + Host | A: "Step ek — video upload karo." H: "Bas? Koi editing nahi?" A: "Bas. Ye dekho." | T3 full-screen demo: upload → captions generating ON the words | Step 1 + micro-payoff |
| 18–25s | Host (roast beat) | "Main toh ek-ek word type karke buddha ho jaata tha…" A (deadpan): "Haan, dikh raha tha." | T2 host close-up, record-scratch SFX, punch-in | Humour + re-hook, doubt voiced |
| 25–35s | Assistant | "Step do — style choose karo. Ek hi accent colour. Zyada rang = sasta look." H: "Ouch. Sach hai." | T3: style picker, good vs cluttered example split | Shortest step in middle, design tip = save-worthy |
| 35–42s | Assistant | "Lekin asli trick step teen mein hai — galti yahi sab karte hain…" | T1, lights dip slightly, anticipation pause 0.3s silence | Biggest re-hook, second loop opened |
| 42–50s | Assistant + Host | A: "Caption ko chin ke neeche, centre mein rakho — warna Instagram ke buttons use kha jayenge." H: "OH. Isiliye mere captions kat rahe the!" | T3: safe-zone overlay demo, wrong vs right | **Macro-payoff** — aha moment |
| 50–53s | — (no dialogue) | On-screen summary card: tool name + 3 steps + prompt tease (too dense to read fully) | T4 summary card | Save-bait interrupt |
| 53–58s | Host + Assistant | H: "Mujhe woh prompt-list chahiye!" A: "Comment **TOOL** — main bhej dunga. Aur haan…" H (to camera, loop line): "…ye captions maine haath se NAHI likhe!" | T4 CTA card: keyword huge in accent, then match-cut to frame 1 composition | One CTA, said + shown, seamless loop |

**Host ≈ 38% of words, Assistant ≈ 62%. Lines: max 10 words. Visual change: every 1.5–2.5s micro, scene change every 3–8s. Payoffs at ~16s, ~33s, ~48s.**

### 3. Pre-flight checklist (tape this above the desk)
1. One idea? Hook text + result in frame 0.0? Word count fits duration at slow pace, read aloud?
2. Every scene uses a template, the palette, the type scale? Accent colour only on assistant/payoff/CTA?
3. No static frame >4s? Graphic lands ON its word? No linear easing? Ground shadow + light consistent?
4. Micro-payoff every ~5s? Re-hook at ~8s, ~20s, ~35s? CTA only after payoff, one keyword?
5. Last line loops to first? Captions inside safe zone, 1–4 words/group?
6. After posting: note dip timestamps at 48h, write ONE fix for the next reel. That — not a redesign — is iteration.

## Could not verify / open questions
- **No platform-published retention benchmark exists** for Reels/Shorts pace, 3s-hold %, or completion %. All such numbers above are labelled aggregator/community figures and sources disagree (e.g. 60%+ skip-in-3s in large-sample Socialinsider reporting vs 70–85% hold claimed for winners in small samples). The creator must benchmark against their own account.
- **Caption-style retention lifts** (+20–50% claims by caption-tool vendors) have no public controlled test behind them; the one controlled study found is small (n=49, language learners, movie clips) and cuts against aggressive keyword-only styling.
- **Full-screen vs character ratio (60/30/10)** is a blueprint recommendation synthesised from hierarchy/learning principles, not a published standard.
- Meta-Ipsos India figures are **Meta-commissioned** survey data (4,000+, 23 cities), not independent measurement; Naukri/Randstad/Deloitte figures are via secondary summaries, not the original reports read in full.
- The creator's actual retention graphs, follower demographics (Instagram Insights), and current design files were not available — the blueprint assumes the format as described in the mission.
